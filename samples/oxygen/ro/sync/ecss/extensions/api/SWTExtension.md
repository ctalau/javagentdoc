# Interface: `SWTExtension`

**Package:** [`ro.sync.ecss.extensions.api`](README.md)

**Fully Qualified Name:** `ro.sync.ecss.extensions.api.SWTExtension`

**Extends:** [`ro.sync.ecss.extensions.api.Extension`](./Extension.md)

## Description

This interface marks extension classes that are available only in the
 Eclipse SWT Oxygen application. E.g.: com.oxygenxml.editor.editors.TextDnDListener 
 and com.oxygenxml.editor.editors.author.AuthorDnDListener
