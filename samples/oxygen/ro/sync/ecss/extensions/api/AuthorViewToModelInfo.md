# Interface: `AuthorViewToModelInfo`

**Package:** [`ro.sync.ecss.extensions.api`](README.md)

**Fully Qualified Name:** `ro.sync.ecss.extensions.api.AuthorViewToModelInfo`

## Description

Used to obtain the node whose graphic representation contains a certain point
 in the Author viewport.

## Methods

### `getOffset()`

It is located within the bounds of the determined AuthorNode
 which also contains the given position.

**Returns:** `int`

### `getAuthorNode()`

**Returns:** [`ro.sync.ecss.extensions.api.node.AuthorNode`](node/AuthorNode.md)
