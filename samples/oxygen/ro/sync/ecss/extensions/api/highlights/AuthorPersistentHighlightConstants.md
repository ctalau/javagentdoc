### `COMMENT_ID`

**Type:** `java.lang.String`

This is first set when a reply is added to the highlight, and will be used as
 parent id for all its replies. 
 

 The value is `id`.

### `COMMENT_PARENT_ID`

**Type:** `java.lang.String`

The parent ID is set on a comment that is a reply to another highlight.
 Its value is the same as the value of the parent's #COMMENT_ID 
 property value.  
 

 The value is `parentID`.
