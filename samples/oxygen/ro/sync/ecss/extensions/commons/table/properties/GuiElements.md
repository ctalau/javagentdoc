# Enum: `GuiElements`

**Package:** [`ro.sync.ecss.extensions.commons.table.properties`](README.md)

**Fully Qualified Name:** `ro.sync.ecss.extensions.commons.table.properties.GuiElements`

## Description

The GuiElements#RADIO_BUTTONS type means that the values will be presented 
 using radio buttons from the same group.
 The GuiElements#COMBOBOX type means that the values will be presented 
 using a combobox.
