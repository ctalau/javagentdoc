# Interface: `URLChooserPluginExtension2`

**Package:** [`ro.sync.exml.plugin.urlstreamhandler`](README.md)

**Fully Qualified Name:** `ro.sync.exml.plugin.urlstreamhandler.URLChooserPluginExtension2`

**Extends:** [`ro.sync.exml.plugin.urlstreamhandler.URLChooserMenuExtension`](./URLChooserMenuExtension.md), [`ro.sync.exml.plugin.PluginExtension`](../PluginExtension.md)

## Description

Allows the user to browse a repository of resources 
 (usually by displaying a chooser dialog) and to select one or more resources for 
 opening in Oxygen. 
 
 The user can access the entire workspace API.
