# Interface: `CacheableUrlConnection`

**Package:** [`ro.sync.exml.plugin.urlstreamhandler`](README.md)

**Fully Qualified Name:** `ro.sync.exml.plugin.urlstreamhandler.CacheableUrlConnection`

## Description

For example, a connection that connects to a remote server to retrieve data should implement this interface
 while a connection that reads data from the local file system may not.
